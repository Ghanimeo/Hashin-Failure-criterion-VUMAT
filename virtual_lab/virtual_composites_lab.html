Universal testing machine

Tensile coupon, 250 × 25 mm, 2 mm/min. Measure each coupon, then pull it.

Stress–strain

Stress from the nominal (measured) cross-section. Strain from the clip-on extensometer.

Coupon log

Raw data

Each coupon: width, thickness, peak load, failure location, and the load–strain record. Copy into Excel, Python or MATLAB.

D3039 rules used for grading: chord modulus between 1000 and 3000 µε; strength = peak load / (w·t); coupons that broke in or at the grips (location code G) are invalid and must be excluded.
